# Interactive Room — механики окружения на UE5

Небольшая комната - головоломка на **Unreal Engine 5** и **Blueprints**. Чтобы открыть выход, игрок должен активировать несколько механик окружения.

Главное в проекте — не отдельные объекты, а **то, как они связаны между собой**. Каждая механика переиспользуемая и настраивается прямо в инстансе на уровне. Объекты общаются через интерфейсы и event dispatchers, поэтому можно собрать новую головоломку **без правки Blueprint-кода**.

---

## Механики

| Blueprint | Что делает | Основные настройки (Instance Editable) |
|---|---|---|
| `BP_Door` | Плавно открывается и закрывается через Timeline. Реагирует на событие и не привязана к конкретному триггеру | Угол / смещение открытия, скорость, начальное состояние |
| `BP_PressurePlate` | Срабатывает, пока на ней стоит игрок или физический куб | Допустимые классы акторов, «залипание» после нажатия |
| `BP_Lever` | Взаимодействие по клавише `E` через `BPI_Interactable` | Одноразовый / переключатель |
| `BP_PuzzleController` | Ждёт срабатывания N активаторов и открывает целевую дверь | Массив активаторов, целевой актор |
| `BPI_Interactable` | Blueprint Interface для всего, с чем может взаимодействовать игрок | — |


---

## Как это устроено

```
 BP_Lever ─────────┐
                   ├──► OnActivated (Event Dispatcher) ──► BP_PuzzleController ──► BP_Door.Open()
 BP_PressurePlate ─┘                                        (все N активны?)
```

## Запуск

**Движок:** Unreal Engine 5.8.3

**Управление:** `WASD` — движение · `Space` — прыжок · `E` — взаимодействие
